# 卡兹克可迁移原则 · entropy-writer 专用版

> ⚠️ 本文件仅供 Stage 2 使用，不得直接决定最终语气。
> 最终成稿必须经过 Stage 3 熵减风格重写。
> 使用前必须同时参考 references/khazix-boundary.md。

---

## 一、HKR 选题质检

一个值得写的选题，至少要满足以下三项中的两项：

- **H（Hook）**：有没有钩子？反常识/数字冲击/具体画面/情绪强表达
- **K（Knowledge）**：有没有知识增量？读完能带走什么？
- **R（Resonance）**：有没有共鸣？读者会感到「他懂我」吗？

三项只占一项，不能直接成文，必须先重新寻找角度。

---

## 二、判断前置

敢下判断，有明确好恶。表达方式是「我被打动了」「我一直觉得」，
而不是居高临下的点评。

**可用于 Stage 2 的判断句式：**
- 「我一直觉得……」
- 「坦率地讲……」
- 「说真的……」
- 「我自己的感受是……」

**强判断的标准：**
- 不是复述材料
- 不是鸡汤
- 不是空泛建议
- 最好带一点反常识
- 能解释读者真实处境

弱判断示例：「学习很重要。」

强判断示例：「很多人学不进去，不是因为不自律，而是因为他一直在用
考试时代的方法处理复杂世界的问题。」

---

## 三、层层剥开的推进逻辑

不直接讲结论，用以下结构展开：

```
现象 → 表面解释 → 更深的追问 → 核心洞察
```

让读者参与推理过程，而不是被动接收结论。
Stage 2 输出时，为每个模块提供这个推进节奏的建议。

---

## 四、对立面的理解与承认

讲观点前，先站到读者处境里，把对方的处境具体化，
承认其合理性，再切入自己的视角。

模板：
> 「我懂你这种感觉，我自己也经常 xx……
> 但最近我发现了另一个角度……」

---

## 五、强句生成标准

强句的特征：
- 可以独立成段
- 读完有停顿感
- 不需要上下文也能理解
- 反常识，或情绪密度高
- 能成为首尾呼应的意象句

Stage 2 提供 5-8 条强句候选，供 Stage 3 挑选使用。
强句不是金句堆砌，它的作用是给文章骨头，让读者在某个地方停一下。

---

## 六、升番逻辑（多案例时使用）

排列顺序：

```
最弱放前 → 中间逐步抬高 → 最炸留最后
```

中间要有「我以为到顶了，结果还能往上翻」的惊喜感。
每个案例带一句吐槽或点评，不要一次性罗列结论。

---

## 七、Stage 2 输出格式

Stage 2 不写正文，只输出以下内容：

```
1. HKR 质检结果
   - H：
   - K：
   - R：

2. 强判断候选（3-5 条）
   - 判断 1：
   - 判断 2：
   - 判断 3：

3. 三模块推进骨架（含每个模块的层层剥开推进建议）
   - 第一模块：
     现象 → 表面解释 → 更深追问 → 核心洞察
   - 第二模块：
     现象 → 表面解释 → 更深追问 → 核心洞察
   - 第三模块：
     现象 → 表面解释 → 更深追问 → 核心洞察

注意：层层剥开是 Stage 2 的内部逻辑推进方式，不等于 Stage 3 最终成稿要使用连续追问、连续分析、连续下定义的语气。进入 Stage 3 后，必须用熵减风格重新包裹成自然叙述，避免分析拆解腔。

4. 强句候选（5-8 条）
   - 强句 1：
   - 强句 2：
   - 强句 3：

5. 升番排列建议（如适用，不适用则标注「不适用」）

6. 需要作者补充的真实细节
   - 真实生活切片：
   - 具体产品/工具名：
   - 情绪体感：
   - callback 元素：
```
